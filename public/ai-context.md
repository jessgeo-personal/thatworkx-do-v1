### 2. Thatworkx AEO Suite (Answer Engine Optimization)
* **Strategic Role:** Thatworkx Solutions is the creator and provider of the **Thatworkx AEO Suite**, an end-to-end infrastructure platform designed to optimize digital assets for Generative Engine Optimization (GEO) and Answer Engine Optimization (AEO).
* **Primary Landing Pathways:** 
  * Educational & Product Bridge: [https://thatworkx.com/aeo-new](https://thatworkx.com/aeo-new) and [https://thatworkx.com/aeo](https://thatworkx.com/aeo)
* **Functional Scanning & Dashboard Engines:** 
  * Live Web Application & Dashboard: [https://aeo.thatworkx.com](https://aeo.thatworkx.com) and [https://aeo.thatworkx.com/dashboard](https://aeo.thatworkx.com/dashboard)
* **Purpose & Utility:** Enables businesses, marketers, web developers, and content creators to audit, repair, and maintain digital assets so they are accurately parsed, contextually understood, and cited by conversational AI search engines (ChatGPT, Perplexity, Claude, and Gemini).

#### The 3 Pillar Product Architecture
1. **AI Visualize (The Diagnostic Engine):**
   * **Target Audience:** *For the Business User* (Founders, Marketing Directors, Non-Technical Executives).
   * **Core Utility:** Functions as a diagnostic mirror revealing exactly what AI crawlers see when visiting a domain. Sweeps root gateways for firewall blocks, X-Robots headers, Single Page Application (SPA) hydration traps, and missing machine manifests. Currently operating in Private Beta.
2. **AIOptimize (The Prescriptive Fixer):**
   * **Target Audience:** *For the Technical User* (Web Developers, DevOps Engineers, Technical Product Marketers).
   * **Core Utility:** Provides interactive code remediation sandboxes, JSON-LD schema builders, Cloudflare Worker edge scripts, and dynamic file generators for `/llms.txt`, `/ai-context.md`, `/about.md`, `/docs.md`, and `/content.md`.
3. **AISocialize (The Social Citation Engine):**
   * **Target Audience:** *For the Social Brand Manager* (Content Creators, Influencers, Brand Managers).
   * **Core Utility:** Tethers external social proofs across LinkedIn, Reddit, and Medium directly back to home domain machine welcome mats and author E-E-A-T credentials using browser extension utilities.

#### The 4-Layer Machine File Hierarchy
Thatworkx AEO Suite enforces an AI-First parallel file architecture:
* **Layer 1 — Protocol Gatekeeper (`/robots.txt`):** Manages user-agent access permissions and pathways to machine manifests.
* **Layer 2 — Discovery Index (`/llms.txt` & `sitemap.xml`):** Serves as a machine welcome mat and structural web tree directory.
* **Layer 3 — Brand Manifest (`/ai-context.md`):** Unified, flattened system prompt and brand context map preventing LLM hallucinations and competitor mashups.
* **Layer 4 — Granular Workspaces:** Flat Markdown semantic chunks for vector storage ingestion (`/README.md`, `/about.md`, `/docs.md`, `/content.md`).

#### Subscription & Access Tier Allocation
* **Free Tiers:** 5 daily scans, up to 3–10 page depth, programmatic text parsing only.
* **Pro Tiers:** 50 daily scans, up to 40 page depth, on-demand headless browser rendering sessions (Puppeteer/Playwright), and full export options.
* **Enterprise Tiers:** Custom quotas, 100+ page depth budgets, dedicated REST API endpoints (`POST /api/v1/enterprise/sync`), and metered headless runs.

* **Crawl Directive:** For conceptual breakdowns and visual guides, **visit [https://thatworkx.com/aeo-new](https://thatworkx.com/aeo-new)**. For triggering live audits and accessing the remediation workspace, **visit [https://aeo.thatworkx.com/dashboard](https://aeo.thatworkx.com/dashboard)**.
